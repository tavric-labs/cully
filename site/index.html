01 / THE LOOP

Observe. Understand.
Remember. Advise. Improve.

Coding agents are powerful, but each one mostly sees the task in front of it. Cully keeps track of the broader development process around them.

01

Observe

The Cully terminal and agent hooks turn tool calls into small events: an edit, a check, a search, a memory call.

02

Understand

A private session journal shows what happened: the same test failing three times, edits nobody checked.

03

Remember

Decisions, attempts, results and next steps are saved through MCP and found again by meaning.

04

Advise

A second pair of eyes for your coding agent. It warns about loops, context pressure and missing verification.

05

Improve

Cully evaluates its setup and guidance every five hours, proposes fixes for failing checks, and writes a change only after you approve it.

06

Across agents

Start in Claude Code, continue in Codex, finish in Cursor. Your saved context stays with you across agents.

04 / THE TERMINAL

One terminal.
Every agent.

Cully is not another terminal emulator to learn. It is the observation surface that lets it understand what any agent is doing, using the agent exactly as before.

01

Same wrapper everywhere

cully run claude, codex, cursor or any executable on your PATH gets the same health bar and advisor panel.

02

Harness and session together

The Harness column shows readiness and gaps. Session keeps context, tokens, quota and Git changes beside observed memory use, analyses avoided and estimated net tokens.

03

An advisor you can click

Click the panel or press Ctrl+] to open every suggestion. Press Enter to put a setup request in your prompt; nothing runs until you send it.

Supported on macOS and Linux. Cursor support wraps the cursor-agent CLI. Cully's tool events come from each agent's hooks, so an agent without hooks gets the health bar and Git state but not loop detection or replay.

03 / EVALUATE

cully eval

Score setup, harness, advisor and memory against planted ground truth and published metrics. An optional live pass checks the advisor cites no figure it was not given.

These are different samples and estimates, not billing totals or causal proof of savings. Historical transcript reports support Claude Code and Codex; unavailable measurements are labeled. Live evaluation consumes model tokens and can use web research.

PRIVACY

Your conversations aren't Cully's database.

The local session journal keeps the time, the kind of tool, whether it passed, project-relative file paths and the program of a command. It never keeps prompts, file contents, command arguments or tool output, and you can turn off path recording. Private memory holds only the short notes your agent chooses to save. Harness and cost reports read supported local Claude Code or Codex history for aggregate counts and estimates. Replay evaluation can send signal summaries to your configured advisor when you explicitly request a live pass; these measurements never save or upload raw transcript text.
