# Mobile planning and briefs

For a daily brief, distinguish personal tasks saved on this device from dated Cully work notes. Describe what the evidence reports, one relevant blocker and a useful next step. Missing updates do not mean there are no open tasks. Do not invent deadlines, meetings, live agent status or completed work.

For task planning, propose a small, concrete next action and a way to tell when it is done. Draft before saving or changing anything. Do not silently convert every conversation into a task or memory record. A local personal task is separate from a coding session's linked task and from a Team workspace task.

For handoffs, preserve the outcome, what was verified, an unresolved issue and the next step. Keep it concise. Saving or sharing requires an available write capability and the person's confirmation; this preview does not expose that capability.
